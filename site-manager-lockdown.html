Blog Builder — Help & Tutorial

Welcome to Blog Builder — a visual editor for creating beautiful blog pages. Here's how to get started:

Adding Blocks
Click + Add Block to insert content. Each block is a section of your page — Hero, Text, Images, Stats, Timeline, and more.
Theme & Fonts
Select the Theme & Fonts block to set your color palette, heading font, and body font. Changes apply across the whole page.
Preview
Use Split View for side-by-side editing, or Full Preview to see the full page. Toggle dark/light mode in the preview toolbar.
Save & Export
Click ⬇ Export JSON to save your project. Use Import JSON to reload it later. Use AI Generate to get a starter JSON from an AI.
